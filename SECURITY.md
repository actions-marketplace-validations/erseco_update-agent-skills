# Security Policy

## Supported versions

Only the latest `v1.x.y` release (and the `v1` tag that points to it) receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/erseco/update-agent-skills/security/advisories/new).
Do not open a public issue.

You can expect an initial response within 7 days. Once a fix is released, the advisory is published
with credit to the reporter unless you prefer otherwise.

## Scope

This action updates third-party skill content. Malicious or unsafe content published by an upstream
skill repository is out of scope: review every skill update before merging it (see the README).
